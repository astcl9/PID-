# PID 数据可视化平台 · 操作指南

## 1. 快速启动（Windows 本地）

```powershell
# 1. 进入项目目录
cd "C:\Users\llin\Documents\ChatGPT\PID数据可视化"

# 2. 创建虚拟环境（首次）
python -m venv .venv

# 3. 激活并安装依赖
.venv\Scripts\Activate.ps1
python -m pip install -e ".[test]"

# 4. 生成样例数据（可选）
.venv\Scripts\python.exe scripts\sample_data.py

# 5. 启动服务
.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8080
```

浏览器打开 **http://localhost:8080** 即可进入主界面。

## 2. 局域网部署

启动命令同上（`--host 0.0.0.0` 已绑定所有网卡）。

1. Windows 防火墙放行 TCP 8080：
   ```powershell
   New-NetFirewallRule -DisplayName "PID-Web" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow
   ```
2. 其他设备浏览器访问 `http://<服务器IP>:8080`。

## 3. 导入数据

### 3.1 文件要求

| 项目 | 规则 |
|------|------|
| 格式 | CSV（.csv）或 Excel（.xlsx / .xls） |
| 必需列 | 时间列（表头含 `timestamp` / `time` / `datetime` / `时间` 等） |
| 信号列 | 列名含 `.PV` / `.SV` / `.SP` / `.MV` 自动归类 |
| 编码 | CSV 自动识别 UTF-8 / GB18030 / UTF-16 |

### 3.2 大小路由（自动）

| 文件大小 | 存储后端 | 说明 |
|----------|----------|------|
| CSV < 100 MB | Parquet + DuckDB | 轻量、零依赖 |
| CSV ≥ 100 MB | PostgreSQL | 需配置数据库连接 |
| XLSX（任何大小） | Parquet + DuckDB | GB 级 XLSX 不走 PostgreSQL |

阈值可通过环境变量 `PID_LARGE_FILE_THRESHOLD_MB` 调整。

### 3.3 上传步骤

1. 点击主界面 **"上传文件"**，选择 CSV/XLSX。
2. 等待上传进度条完成，系统后台自动解析。
3. 导入完成后，文件出现在左侧数据集列表。
4. 点击数据集 → 选择年份 → 点击日历中某一天 → 进入单日曲线页面。

### 3.4 上传大小限制

默认单文件上限 2048 MiB，可通过 `PID_MAX_UPLOAD_MB` 调整。

## 4. 界面功能导览

### 4.1 年度日历页

- 每个格子代表一天，颜色深浅 = 数据完整率。
- 点击某天进入单日曲线。
- 顶部可切换数据集、年份、回路。

### 4.2 单日曲线页

- **时间窗口滑块**：移动查看全天 / 6h / 3h / 1h / 30min / 15min。
- **信号筛选**：勾选 PV / SV / MV 信号。
- **分辨率**：自动 / 10s / 1m / 10m / 1h。
- **智能分段**：下方时间线显示设定值变化、振荡、稳定段等事件。

### 4.3 导出

- **当前窗口 CSV**：导出当前时间窗口的原始数据。
- **分段结果 CSV**：导出智能分段统计表。

## 5. 配置 PostgreSQL（大文件导入需要）

### 5.1 Docker Compose 启动（推荐）

```powershell
$env:PID_POSTGRES_PASSWORD = "your-strong-password"
docker compose up --build -d
```

此模式所有导入都走 PostgreSQL。

### 5.2 本地 PostgreSQL + Parquet 混合

```powershell
# .env 或系统环境变量
$env:PID_POSTGRES_HOST = "127.0.0.1"
$env:PID_POSTGRES_PORT = "5432"
$env:PID_POSTGRES_USER = "pid"
$env:PID_POSTGRES_PASSWORD = "your-password"
$env:PID_POSTGRES_DATABASE = "pid"

# 启动（小文件自动 Parquet，大 CSV 自动 PG）
.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8080
```

> 不设置 `PID_STORAGE_BACKEND=postgres` 时，只有 ≥ 100 MB 的 CSV 才会走 PG，其余走 Parquet。

### 5.3 验证 PG 连接

```powershell
curl http://localhost:8080/health/storage
# 期望返回 {"backend":"postgres","ok":true}
```

## 6. 常用环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PID_MAX_UPLOAD_MB` | 2048 | 单文件上传上限 |
| `PID_LARGE_FILE_THRESHOLD_MB` | 100 | CSV ≥ 此值走 PG |
| `PID_IMPORT_WORKERS` | 2 | 并发导入数 |
| `PID_STORAGE_BACKEND` | parquet | 全局后端（postgres/parquet） |
| `PID_POSTGRES_DSN` | — | 完整 PG 连接串 |
| `PID_DATA_DIR` | ./data | 数据目录 |
| `PID_PARQUET_COMPRESSION` | snappy | Parquet 压缩算法 |

## 7. 数据备份

- **Parquet 模式**：停止服务后，备份项目 `data/` 目录。
- **PostgreSQL 模式**：额外执行 `pg_dump`（见 README 备份章节）。

## 9. 常见问题

| 问题 | 解决 |
|------|------|
| 端口被占用 | `netstat -ano \| findstr :8080`，杀掉对应 PID 或改 `PID_PORT` |
| 大文件导入失败 | 确认 PG 已配置且服务可达；检查 `data/staging` 磁盘空间 |
| 导入后看不到数据 | 确认时间列被正确识别；查看 `/api/imports/{job_id}` 状态 |
| 浏览器打不开 | 确认防火墙已放行；确认 `--host 0.0.0.0` |
| 图表空白 | 检查信号是否勾选；降低分辨率；查看浏览器控制台报错 |
